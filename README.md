# Tic Tac Toe

A clean browser-based tic-tac-toe game built entirely with Python and Streamlit.

## Features

- Play as **X** or **O**
- Play against an unbeatable minimax bot
- Two-player pass-and-play mode for friends
- Match scoreboard and one-click round reset
- Responsive layout for desktop and mobile browsers

## Run locally

```bash
cd tic-tac-toe
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/streamlit run app.py
```

Then open <http://localhost:8501>.

## Try it - <https://play-tic-tac-toe.streamlit.app/>
